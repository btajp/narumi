# Codex App Server による単独議事録生成

作成: 2026-08-29。対象: 0.3.0（実装・ソース検証済み、公開準備中）。

## 1. 今回の公開単位

Codex App Server を優先し、アプリで接続を追加して公式ログインし、
モデルを選び、テキストから議事録を生成する操作までを一つの公開単位にする。
接続一覧への追加だけでは完了としない。

既存のプロバイダ・ワークフロー設計を一度に置き換えず、会議設定に
`minutes_model` を追加する。既存の録画・文字起こし・発話統合・画像読解の設定は維持する。
Codex の選択をそれらの工程へ暗黙に共用しない。
OpenAI API、音声認識 API、複数案の生成・統合、全工程の新設定形式への移行は今回に含めない。

## 2. アプリの操作

1. 「AI 接続」で Codex App Server と接続名を保存する。API キー欄は使用しない。
2. 対応する実行環境を準備し、公式の ChatGPT デバイスログインを開始する。
   表示された確認コードを、専用ボタンで開いた公式ページに入力して承認する。
3. その接続のモデル候補を取得する。接続確認では会議を送信しない。
4. 会議設定またはプロファイルで、接続・モデル・対応する推論設定を選ぶ。
5. OpenAI へのテキスト送信と ChatGPT の利用枠を使うことを確認して設定を保存する。
6. 保存済みの設定を確認し、議事録生成を実行する。保存だけでは生成しない。

`local_only` を自動で変更しない。Codex を使う場合は利用者が
`subscription_ok` または `api_ok` を明示的に選ぶ。
`api_ok` でも Codex の認証を API キー方式へ切り替えない。
新しい会議の自動処理は、利用者が選んだプロファイルと自動処理の指定に従う。

## 3. 契約と設定の互換性

契約は 3.0.0。旧クライアントが受け付けない provider/auth enum と認可 URL の文字列応答を追加する。
新しいアプリ・サーバー・CLI を同時に配布し、古い常駐サーバーへ生成を送らない。

`minutes_model` は次の非秘密情報を持つ。

| 項目 | 意味 |
|---|---|
| `provider` | 今回は `codex-app-server` のみ |
| `connection_id` / `connection_revision` | 選んだ接続と確認時の版 |
| `model_id` | その接続の一覧で確認したモデル ID |
| `parameters.reasoning_effort` | 選択モデルが対応する値。省略時は確認したモデルの既定値を解決 |
| `cache_epoch` | 明示的な新規試行の番号。通常は 0 |

既存ファイルに項目がない場合は従来どおり動作する。
会議設定更新では省略は保持、null は解除であり、オブジェクトは全体を置き換える。
モデル・接続・認証方式・送信許可が不適合なら拒否し、別モデルへフォールバックしない。

Codex を選択した会議の `regenerate` と、生成も行う `register_context` は、
確認した設定全体を `expected_config` に渡す。
会議ロック内で比較し、不一致なら保存・ジョブ作成・外部送信より前に拒否する。

## 4. 実行環境と認証の境界

対応版は Codex CLI 0.150.1。配布版は OpenAI 公式 `rust-v0.150.1` の
Apple Silicon 用 artifact から取得したネイティブ実行ファイルを `.app` に同梱する。
tag commit、artifact URL・SHA-256・サイズ、展開 entry、binary の SHA-256・サイズ・arm64、
OpenAI の Developer ID Team、Apache-2.0 LICENSE / NOTICE を lock と inventory で固定する。
lock は実行時 trust anchor と完全一致しなければビルドを開始しない。
上流署名は保持し、外側のアプリ署名後も hash と署名を再検査する。
「確認・準備」は同梱 binary を narumi 専用領域へコピーして実版・SHA-256 を検査し、
ダウンロードや外部通信を行わない。同梱物が欠落・変更していれば外部インストールへ
切り替えず、配布版の更新または再インストールが必要な状態として停止する。
repo モードでは、公式 npm パッケージの既知の配置先を従来どおり検査できる。
版を特定できない Codex.app 内の実行ファイルや、任意の PATH 上のコマンドは採用しない。
narumi が所有する実行環境と接続ごとの認証領域を使う。
普段の Codex の設定、資格情報、MCP、プラグイン、会話をコピーしない。
グローバルツールの追加インストールや、利用者指定のコマンド実行は提供しない。

各呼出では新しい HOME・CODEX_HOME・作業ディレクトリを作り、
当該接続の認証ファイルだけを安全にコピーする。設定・履歴・SQLite・skills は引き継がない。
正常終了時に更新された認証を保存し、呼出の一時領域を削除する。

認証は公式 App Server の `chatgptDeviceCode` 操作を使う。
`authorization_url` は `https://auth.openai.com/codex/device` に固定し、
`user_code` は 1〜32 文字の ASCII 英数字・ハイフンだけを受け付ける。
開始中の操作だけに両方を一対で返し、完了・取消・失敗・結果不明では両方を消す。
URL・確認コードは一時メモリに保持し、操作記録やログへ保存しない。
他の Codex のログイン用ポートは使わない。デバイス認証を利用できない場合は停止し、
ブラウザ callback や API キーへ自動で変更しない。
ログアウトは選択した接続だけを対象にし、他の Codex 接続には触れない。

生成の出荷条件は、渡したテキスト以外を取り込まず、ファイル操作・コマンド・MCP・
Web 検索などの外部作用を行わず、SDK の会話履歴を残さない構成を固定版で検証すること。
同じモデル ID の専用カタログで shell・ツールを無効にし、MCP・skills・拡張機能も
無効にする。read-only sandbox と承認拒否だけでこの条件を満たしたとは判断しない。
管理設定を迂回せず、条件を満たせない構成は理由を返して拒否する。

内部の固定 provider は ChatGPT 認証を維持し、初期送信先を公式 OpenAI endpoint にする。
request/stream retry は 0、WebSocket は無効にする。ただし SDK 内には
401 拒否後の認証回復、未処理が確定した HTTP/2 NACK の再送、HTTP redirect が残る。
プロセスの全通信が同じ URL へ一度だけ送られることは保証しない。
通常の timeout・切断後の結果不明と、これらの SDK 動作を区別する。

## 5. 再生成・取消・結果不明

議事録の指紋にモデル・実効パラメータ・接続版・実行環境版・アダプタ版・
`cache_epoch` を含める。同じ入力と指紋では外部呼出を行わない。
モデルだけの変更で文字起こしや発話統合をやり直さず、過去の議事録版も上書きしない。

初版では認証アカウント変更と表示名変更を接続版だけで区別できないため、
表示名だけの変更でも接続を選び直した後の議事録生成は新しい試行になる。
文字起こしと発話統合の成果には影響しない。

外部呼出の前に checkpoint を保存し、成功した部分要約を再利用する。
送信後の切断・保存失敗などで結果が不明なら、自動で再送しない。
新しく試すには利用枠を重複消費する可能性を確認し、`cache_epoch` を明示的に増やす。
取消は呼出間だけでなく応答待ち中にも伝え、所有する子プロセスを終了する。

長文は部分要約と段階的な統合で処理する。モデルの入力上限が未確認なら
1 呼出の入力を指示・ブリーフ込みで 12,000 文字に抑え、確認できた場合も最大 24,000 文字とする。
同じ試行の外部要求は最大 64 回、統合は最大 6 段階。要約が縮まらない場合も停止する。
これはアプリの処理上限であり、モデルの context 長や厳密な費用上限の保証ではない。

## 6. 検証

契約・型、保存と再読込、選択モデルの引渡し、禁止送信時の呼出ゼロ、限定再生成、
接続変更との競合、取消、結果不明、秘密非露出を fake で検証する。
固定版プロトコルの検証と、実アカウントへのログイン・実生成は分けて記録する。
実アカウントと会議の送信は明示オプトインとし、通常の CI では実行しない。
署名・公証・配布物照合の後に公開し、実機の UI 確認はインストール済みアプリの更新で行う。
通常テストは fake archive と失敗する download stub を使う。固定した実 artifact の
archive / binary hash、arm64、上流署名、`--version` のオフライン起動も認証なしで検査する。
実 ChatGPT ログイン、実 provider 送信、Apple 公証はこの検査に含めない。

`uv run python scripts/check_codex_protocol.py` は macOS 上の固定 CLI を検証する。
許可した loopback ポートへの接続成功・別ポートへの接続拒否を先に検査し、
専用一時領域・合成テキスト・一時的な偽 API キーだけで実行する。
本番と同じ設定検証・モデルカタログ・生成処理について、指定モデル ID と `tools=[]`、
正常完了、HTTP ヘッダ前と応答途中の切断が結果不明になり要求が増えないことを確認済み。
これは ChatGPT デバイスログインや実モデルの品質を確認した結果ではない。

2026-08-29 の全回帰は Python 3,156 件、Swift 543 件が成功した。
Gaia 実接続 5 件は設定なしで skip、実 Whisper 2 件は opt-in のため対象外。
Python 2 パッケージと Swift の build、ruff check / format、版整合も確認した。
独立レビューの指摘は修正・再確認済み。秘密・ユーザーデータ・成果物の混入は
追加差分のパターン抽出と文脈確認で監査し、専用秘密スキャナは使用していない。
実 ChatGPT ログイン・実生成・更新後の GUI は未検証であり、これらの成功は含めない。
